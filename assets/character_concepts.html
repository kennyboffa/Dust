Character Art Style Concepts

5 different art styles for the Dustwalker protagonist. Each shown at 4x scale.

Style A: Chunky Pixel (Current-ish)

Low-res pixel art with dithered shading. Fallout 2 inspired, 32x48 sprites with ordered dither patterns.

Style B: Clean Vector Pixel

Higher-res clean pixel art. No dithering, smooth gradients via flat color blocks. GBA/SNES style, crisp outlines.

Style C: Silhouette / Limbo Style

Dark silhouette with minimal detail. Atmospheric, moody. Only key features (eyes, weapon gleam) have color.

Style D: Painterly / Hand-drawn

Rough brushstroke look with visible texture. Earthy watercolor palette. Organic, hand-crafted feel like Darkest Dungeon.

Style E: Geometric / Low-Poly

Flat geometric shapes, angular construction. Bold color blocking with minimal detail. Modern indie style like Hyper Light Drifter.
